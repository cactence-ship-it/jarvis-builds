# jarvis-builds

Multi-project repository. Projects:

- `kartal-s-twin/` - Tofaş Kartal S (1997) digital twin. Before any work on it, read
  `kartal-s-twin/CLAUDE.md` (binding rules) and `kartal-s-twin/PROJECT_STATUS.md` (next action).

This repository is PUBLIC: never commit private photos, documents or personal data.

New code is Rust (D-029 in `kartal-s-twin/ENGINEERING_DECISIONS.md`). Existing Python stays and may be
fixed in place; new `.py` files are allowed only under `kartal-s-twin/tools/blender/` and
`kartal-s-twin/tests/`. The PR guard rejects anything else.
